# MC Fencing Website

A modern, mobile-friendly website for MC Fencing — built with **Next.js** and **Tailwind CSS**. This site includes an interactive contact form, services overview, and image gallery for showcasing fencing projects.

## 🚀 Tech Stack

- [Next.js](https://nextjs.org/)
- [React](https://reactjs.org/)
- [Tailwind CSS](https://tailwindcss.com/)
- Pending: To be deployed

## 📂 Features

- ⚡ Fast and responsive UI
- 📞 Contact form with email capture
- 🛠️ Detailed services section
- 📷 Gallery of completed fencing projects
- 📱 Fully mobile-optimized
